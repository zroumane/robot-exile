# Robot Exilé

[Inviter le bot](https://discord.com/oauth2/authorize?client_id=654074392321458176&scope=bot&permissions=16778256)

Dans `.env`

```sh
TOKEN="DISOCRD-BOT-TOKEN"
DEV_DISCORD_ID="null"
```

## Usage

```
Commandes :
.help
  : Afficher ce message
.voice (add|remove) <Id Channel> <?prefix>
  : Ajouter ou supprimer un channel de création vocale
.métier
  : Mettre à jour vos lvl de métiers dans le gdoc
```
