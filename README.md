# Robot Exilé

[Inviter le bot](https://discord.com/oauth2/authorize?client_id=795591898701365308&scope=bot&permissions=16777232)

Dans `.env`

```sh
TOKEN="DISOCRD-BOT-TOKEN"
DEV_DISCORD_ID="null"
```

## Usage

```
Commandes :
.help
  : Afficher ce message
.voice (add|remove) <Id Channel>
  : Ajouter ou supprimer un channel de création vocale
```
